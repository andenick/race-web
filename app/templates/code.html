Code & Reproducibility

The series on this site are built by 11 loaders and 6 processors on public sources (Census ACS, Fed SCF, BLS CPS, BJS, MeasuringWorth, SlaveVoyages). This page documents where every figure comes from, and what does and does not ship with the site.

What ships here. This repository is the website: a FastAPI application, its templates, and the finished CSVs it serves from app/data/. The loaders and processors described below belong to a separate upstream construction project and are not distributed with the site — there is no L##, P## or V## script in this tree, no dependency lockfile pinning the source vintages, and no build stamp. You cannot re-run the construction from what is published here. What you can do is audit the output: every CSV is downloadable, and every series names the public source and table it was drawn from.

How the data are built

Upstream, the dataset is organized as three layers of plain Python. Each layer has a single responsibility, and each stage's output feeds the next:

LayerRoleWhat it does
Loaders L## Fetch raw data One loader per public source. Each calls a public API (or reads a public download) and caches the raw response with a date stamp. Loaders do no math — they fetch faithfully and stop. L10 is the exception: its source is a printed historical volume, so its five rows were OCR-extracted from the page and hand-checked rather than fetched.
Processors P## Harmonize & derive Take raw loader output, harmonize race categories across sources, deflate nominal to real dollars, and compute derived series (ratios, gaps, shares). Every formula is documented in code so a reviewer can verify it.
Library Synthesize & validate Aggregators assemble the cross-panel synthesis; validators (V##) cross-check series against independent sources and assert internal consistency before any file is published.

The eleven rows above are the complete set of sources behind every figure here — nothing is fetched from a source that is not listed.

Processors & validation

Processors (P01 wealth timeseries, P02 income & poverty, P03 employment, P05 housing, P06 education, P10 demographics) transform raw loader output into the harmonized, race-consistent series published here. Cross-source validation runs in that upstream pipeline, not on this site. Its result is recorded in the validation field of series_registry.json, which reports V10 (demographics) 7/7 and V_ALL (consolidated) 16/16 passing across wealth, employment, income, poverty, housing, criminal justice and the slave trade. No validator, log or report artifact ships in this repository, so treat that line as the pipeline's own record rather than something you can re-run here.

Data not advocacy

The pipeline's only job is faithful reconstruction. It does not smooth or interpolate, and it fills no gap with a fabricated value — every data gap is documented, never hidden. Where an original source publishes imputed estimates it is said so and the figure is carried through as published: the trans-Atlantic slave-trade series is the case that matters, since SlaveVoyages reports embarked and disembarked counts as TAST imputed totals correcting for incomplete voyage records. Those imputations are the source's, labelled as such, not ours. For the full provenance of each figure (source vintage, race-category harmonization, known limits), see Methodology & Provenance.
